# 2. Kubernetes and OpenShift CLI and APIs

```bash
# login mit Token (muss vorher in Web-Frontend erstellt werden)
oc login --token=sha256-fypX...Ot6A \
--server=https://api.lab.example.com:6443

# login mit username/pass
oc login -u admin https://api.lab.example.com:6443

# über webbrowser einloggen:
oc login --web api-url
```

**Infos zum Cluster erhalten**

```bash

# Cluster Version ermitteln
oc version

# URL vom Control Plane ermitteln
oc cluster-info

# alle unterstützten API Versionen anzeigen
oc api-versions

# Clusteroperatoren auflisten
oc get clusteroperator

# Status von Ressourcen ausgeben
oc status -n openshift-authentication

# verfügbare Felder und Beschreibungen anzeigen
oc explain services

```

# Kubernetes Ressourcen anzeigen 
💡**Wichtig**
- die API Group kann durch das Feld APIVERSION herausgefunden werden
- z.B. hat die Jobs Ressource die Gruppe "batch" und die Version "v1"

```bash
oc api-resources                                   # alle unterstützten Ressourcen anzeigen

oc api-resources --namespaced                      # namespaced scoped

oc api-resources --namespaced=false                # nicht namespaced scoped

oc api-resources --api-group ''                    # core API group

oc api-resources --api-group apps                  # apps API group

oc api-resources --api-group config.openshift.io  # OpenShift configuration API group

```
## Health of an OpenShift Cluster
```bash
oc get operators                                          # installierte Operatoren

oc get clusteroperators                                   # per Default istallierte Clusteroperatoren 

oc adm top pods -A --sum                                  # Zeigt Ressourcen aller Pods inklusive Summe

oc adm top pods etcd-master01 \                           # zeigt Ressourcen von allen Containern eines Pods in einem NS
-n openshift-etcd --containers

oc get node master01 -o jsonpath=\                        # Allocatable: Wieviel CPU kann noch vergeben werden
'Allocatable: {.status.allocatable.cpu}{"\n"}'\           # Capacity: Wieviel CPU Kapaziät steht überhaupt zur Verfügung
'Capacity: {.status.capacity.cpu}{"\n"}'

oc adm node-logs master01 -u crio --tail 5                # die letzten 5 Node Logs des Crio Service anzeigen

oc debug node/master01                                    # auf den Node zugreifen                          
chroot /host                                              # auf Host binaries zugreifen
systemctl status kubelet                                  # Status des kubelets anzeigen

oc adm must-gather --dest-dir /home/student/must-gather   # Diagnose und Debugging Infos sammeln

oc adm inspect clusteroperator/openshift-apiserver \      # Debugging Infos vom api-server sammeln (letzte 5 min)
--dest-dir /home/student/inspect --since 5m

```

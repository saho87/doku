# 2. Kubernetes and OpenShift CLI and APIs

```bash
# login mit Token (muss vorher in Web-Frontend erstellt werden)
oc login --token=sha256-fypX...Ot6A \
--server=https://api.lab.example.com:6443

# login mit username/pass
oc login -u admin https://api.lab.example.com:6443

# über webbrowser einloggen:
oc login --web api-url
```

**Infos zum Cluster erhalten**

```bash

# Cluster Version ermitteln
oc version

# URL vom Control Plane ermitteln
oc cluster-info

# alle unterstützten API Versionen anzeigen
oc api-versions

# Clusteroperatoren auflisten
oc get clusteroperator

# Status von Ressourcen ausgeben
oc status -n openshift-authentication

# verfügbare Felder und Beschreibungen anzeigen
oc explain services

```

# Kubernetes Ressourcen anzeigen 
💡**Wichtig**
- die API Group kann durch das Feld APIVERSION herausgefunden werden
- z.B. hat die Jobs Ressource die Gruppe "batch" und die Version "v1"

```bash
oc api-resources                                   # alle unterstützten Ressourcen anzeigen
oc api-resources --namespaced                      # namespaced scoped
oc api-resources --namespaced=false                # nicht namespaced scoped
oc api-resources --api-group ''                    # core API group
oc api-resources --api-group apps                  # apps API group
oc api-resources --api-group config.openshift.io  # OpenShift configuration API group


```
